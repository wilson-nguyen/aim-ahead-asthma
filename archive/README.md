# Archive

Files kept for the record that are not part of the analysis workflow.

- `notebook_patches/`: one-off scripts that edited the analysis notebooks during the 2026 revision. All have been applied, and the notebooks in `notebooks/` already contain the result, so there is no reason to run them again.
- `notebooks/05_top10_sensitivity.ipynb`: the original reduced-model notebook, replaced by `run_reduced_model_and_figures.py`.
- `freeze_and_manifest.py`: the utility that took a snapshot of the pipeline before the corrections.

The tagged release `v3.4-R3-final` has these files in their original locations.
